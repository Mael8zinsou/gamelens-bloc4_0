# Captures d ecran

Images d interfaces graphiques, deposees a la main : elles ne peuvent pas etre
automatisees depuis ce depot.

Nommer le fichier exactement comme l identifiant attendu, en .png, puis relancer
`python outils/generer_support.py` : le cadre reserve du PPTX est remplace par
l image. La liste des identifiants et de ce qu il faut cadrer est a la fin de
`docs/support_soutenance.md`.
